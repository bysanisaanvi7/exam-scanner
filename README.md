
# AI Exam Scanner

An AI-powered exam evaluation system that converts handwritten student answer sheets into text and evaluates answers using teacher-provided answer keys.

## Features

- Student portal for answer-sheet uploads and results
- Teacher portal for exams, answer keys, and marking schemes
- Handwriting recognition
- Automatic MCQ evaluation
- AI-assisted descriptive answer evaluation
- Teacher review of uncertain evaluations

## Technology Stack

- Python and Flask
- React
- SQLite
- Handwriting recognition and AI evaluation models

## Status

Currently in development.
